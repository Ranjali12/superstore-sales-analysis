
# Superstore Sales Analysis & Forecasting Dashboard

## Project Overview
Developed an interactive Power BI dashboard to analyze Superstore sales performance, profitability, customer segments, and regional trends. The project also includes 15-day sales forecasting to support data-driven business insights.

## Dashboard Preview

### 1. Sales Analysis Dashboard
Analyzes overall sales, profit, quantity, customer segments, payment modes, product categories, and geographical performance.

### 2. Sales Forecasting Dashboard
Visualizes historical sales trends, state-wise performance, and 15-day sales forecasts with a 95% confidence interval.

## Key Insights
- Analyzed sales and profitability across different product categories and regions.
- Identified top-performing states and customer segments.
- Forecasted sales trends over a 15-day horizon.
- Estimated $79.28K in sales using a historical average-based projection.
